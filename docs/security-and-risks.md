# 账号安全与第三方充值风险

> 最后核实日期：2026-08-01

第三方协助充值不是 OpenAI 官方服务。便利性不能消除账号、付款来源、履约和售后风险。下单前应确认交付形式并阅读实时条款。

## 永远不要公开提交的信息

- 账号密码和邮箱密码；
- 邮箱、短信或身份验证器验证码；
- API Key、访问 Token、Cookie 或会话信息；
- 完整银行卡号、安全码和支付账户凭据；
- 身份证件、未脱敏订单或其他个人资料。

尤其不要把这些内容写入 GitHub Issue、Discussion、Pull Request、评论、代码或仓库文件。Git 历史中的秘密即使后来删除，也可能仍可恢复。

## 第三方服务的检查要点

1. 明确是本人账号协助充值，还是交付独立账号。
2. 了解需要提供什么信息，以及完成后是否应修改密码。
3. 核对服务周期、续费方式、最终金额和订单凭证。
4. 阅读异常处理、退款条件及不在售后范围内的情况。
5. 拒绝未经证实的官方合作、永久稳定或绝对安全承诺。

## 防诈骗提醒

不要因低价、倒计时或所谓“名额”跳过核对。不要安装来源不明的远程控制软件，不向私人账户付款而不留订单凭证，不让陌生人控制邮箱。遇到要求额外转账才能解冻订单、索要验证码或诱导关闭安全设置时，应停止交易并通过正式渠道核实。

## 出现异常后

先保护邮箱和账号，退出陌生会话、修改密码并保留必要证据。联系实际下单渠道时仅提供最少必要信息。公开求助截图需要遮盖邮箱、订单号、付款资料和其他识别信息。
