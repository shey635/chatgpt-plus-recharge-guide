# ChatGPT Plus下单前检查清单

> 最后核实日期：2026-08-01

## 需求与账号

- [ ] 我需要的是 ChatGPT 聊天订阅，不是 API 额度。
- [ ] 免费方案确实不能满足当前需求。
- [ ] 我已确认使用本人原账号、新账号还是独立成品号。
- [ ] 我长期控制账号邮箱和安全设置。

## 套餐与费用

- [ ] 我在购买当天核对了套餐名称和当前权益。
- [ ] 我核对了币种、税费、汇率、服务费和最终金额。
- [ ] 我知道服务周期从何时开始、何时结束。
- [ ] 我知道是否自动续费以及如何取消。

## 第三方服务

- [ ] 我确认服务方不是 OpenAI 官方网站或官方客服。
- [ ] 我看懂交付的是充值服务还是独立账号。
- [ ] 如果商品需要 Token，我知道它不是 API Key，而是可能提供会话访问能力的敏感凭据。
- [ ] 我已核对 Token 的用途、订单指定提交渠道和办理完成后的安全建议。
- [ ] 我已阅读到账说明、售后范围和退款条件。
- [ ] 页面未说明的事项，我已在付款前取得可保存的答复。
- [ ] 我不依赖“绝对安全”“永久稳定”或“保证成功”等承诺。

## 安全与留痕

- [ ] 我不会在 GitHub Issue、Discussion、评论、群聊或其他公开位置提交密码、Token 或订单隐私。
- [ ] 我不会向身份不明的人或非订单指定渠道提供 Token。
- [ ] 我不会提供邮箱密码、邮箱或短信验证码、Cookie、API Key 或完整付款信息。
- [ ] 我不会安装来源不明的软件或把邮箱控制权交给陌生人。
- [ ] 我会保存订单号、付款状态、有效条款和必要沟通记录。
- [ ] 完成后我会核对订阅状态，并检查陌生登录会话。

任何一项无法确认，都建议暂停付款，先查清规则。
