# ChatGPT Plus付款与订阅故障排查

> 最后核实日期：2026-08-01

本指南提供排查顺序，不保证解决所有问题。不要在公开渠道提交密码、验证码、Token、Cookie、完整银行卡信息或含隐私的订单截图。

## 通用原则

1. 先停止重复付款，记录错误原文和发生时间。
2. 确认登录邮箱、购买渠道和订单号。
3. 区分已入账扣款、预授权和失败记录。
4. 在对应渠道核对订阅：官方网页、应用商店或第三方订单页。
5. 只向正确支持渠道提供最少必要信息。

## 卡被拒绝或付款失败

核对余额或额度、卡片有效期、账单信息、币种和银行通知。询问发卡机构是否拒绝了相应交易。页面错误不应被武断归因于网络或地区，原因不明时按官方支持指引处理。

## 扣款后订阅未显示

确认扣款性质，核对是否登录错账号。刷新订阅管理页并等待合理处理时间。应用内订单去商店订阅记录核查；第三方订单通过其正式订单渠道核查。在前一笔状态清楚前不要再次支付。

## 自动续费失败

查看付款方式是否过期或额度不足，确认订阅由哪个渠道管理。续费失败后权益、价格或恢复方式可能变化，以当前页面为准。

## 订阅状态消失

保存当前状态、订单号和付款记录，依次排除登录错账号、续费失败、退款或争议、商店同步及第三方订单异常。不要在未核实前断言封号或再次购买。

## 账号安全异常

若发现陌生登录或设置变化，优先退出其他会话、修改密码并检查邮箱安全。不要把验证码、Token 或 Cookie 交给声称可以“修复账号”的陌生人。

## 联系支持时可准备

- 订单号与购买时间；
- 登录邮箱的脱敏形式；
- 错误原文与不含敏感信息的截图；
- 扣款是入账还是待处理；
- 已完成的排查步骤。

不要提交完整卡号、安全码、密码、验证码、Token 或 Cookie。
